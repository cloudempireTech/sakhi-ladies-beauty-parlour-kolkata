# Sakhi Ladies Beauty Parlour website

A responsive multi-page static website for Sakhi Ladies Beauty Parlour in Rajdanga, Kasba, Kolkata. Built with semantic HTML, CSS, and vanilla JavaScript.

## Pages

- Home
- About
- Services
- Hair & Style
- Beauty & Wellness
- Gallery
- FAQ
- Contact

## Accessibility and performance

- Keyboard-friendly navigation, visible focus states, skip link, semantic landmarks, descriptive alt text, touch-sized actions, reduced-motion support, responsive image sources, and optimized WebP media.
- Unique title, meta description, canonical URL, and H1 per page; verified JSON-LD, `sitemap.xml`, and `robots.txt`.
